# portfolio-landing-page

Landing Page para portfóio pessoal, buscando destacar as habilidades de design e desenvolvimento web, com foco no estilo minimalista e confortável, fazendo sentido com o setor de saúde (tema pastel, pouco esforço cofnitivo etc.).

# Tecnologias utilizadas

- Tailwind CSS
- React
- Vite

# Instalação

1. Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Navegue até o diretório do projeto:

```bash
cd portfolio-landing-page
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```
